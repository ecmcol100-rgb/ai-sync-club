# ItemLabel · Section2 Graphics — 컴포넌트 사양서

**용도**: 항목 라벨 자막(전 편 공통) + 섹션 2의 두 설명 그래픽
**첫 적용**: 기본 시리즈 ① 목양·목음편
**공통 제약**: 본문 그래픽은 `CONTENT_MAX_Y = 686` 안에서 끝날 것. 애니메이션 중 최대 발자국 기준

---

# A. ItemLabel — 항목 라벨 자막

## A-1. 목적

9항목 구조를 시청자가 인지하게 하는 장치입니다. 섹션 3·4에서 항목이 바뀔 때마다 좌상단에 소형 라벨이 뜹니다.

**이 시리즈의 뼈대가 9항목 체계**이므로, 라벨이 없으면 시청자는 두 체질 설명이 같은 순서로 흘러간다는 것을 알아채지 못합니다. 섹션 3과 4의 대칭이 화면으로 드러나는 유일한 장치입니다.

## A-2. 인터페이스

```ts
type Props = {
  label: string;        // '외형' | '성격' | '직업' | '운동' | '질병' | '건강법' | '유명인'
  accentColor?: string; // 미지정 시 해당 섹션 체질색
};
```

노출 구간은 상위 Sequence가 제어합니다. 컴포넌트에 타임코드를 넣지 마십시오.

## A-3. 규격

- **화면 좌상단.** 소형. 본문 그래픽을 가리지 않을 것
- 짧은 페이드인 + 미세 슬라이드. 0.3초 안팎
- 항목이 바뀌면 이전 라벨은 사라지고 새 라벨이 등장 — **동시에 두 개가 뜨지 않습니다**
- 색은 해당 섹션의 체질색(`CONSTITUTION_ACCENTS`) 사용
- **직업 캡션(`career`)과 나란히 배치될 수 있습니다.** SafetyCaption의 career는 자막 슬롯(y 686~) 좌측에 있고 ItemLabel은 좌상단이므로 세로로 떨어져 있지만, 실제 합성에서 시선이 분산되지 않는지 확인하십시오

## A-4. 목양·목음편 라벨 순서

| 섹션 | 라벨 순서 |
|---|---|
| 3 목양체질 | 외형 → 성격 → **직업** → 운동 → 질병·건강법 → 유명인 |
| 4 목음체질 | 외형 → 성격 → **직업** → 운동 → 질병·건강법 → 유명인 |

**두 섹션이 같은 순서라는 점이 중요합니다.** 이 대칭이 이 편의 설계이므로 라벨 위치·크기·등장 방식이 양쪽에서 완전히 동일해야 합니다.

**섹션 3의 라벨 전환 지점 하나만 주의**하십시오 — [성격]에서 [직업]으로 바뀌는 지점은 *"그래서 독자적인 사업을 하는 사람이 많고"* 문장입니다. 그 앞까지가 성격입니다.

# B. Section2b — 담즙·길항 도식

## B-1. 전달해야 하는 것

> 간이 담즙을 만든다 → 그래서 고기를 잘 소화한다
> **그런데** 음식은 소화만이 아니라 **약한 장기를 돕는 쪽**으로 고른다
> → 육식은 길항관계에 있는 약한 폐·대장을 보강한다

**"그런데"의 전환이 화면으로 보여야 합니다.** 앞의 소화 이야기가 틀린 것이 아니라 **한 걸음 더 나아가는 것**이라는 관계입니다. 앞 내용을 지우거나 X를 치는 연출은 쓰지 마십시오 — 대본에서 부정형을 피한 이유와 같습니다.

## B-2. 연출 구성

| 단계 | 화면 |
|---|---|
| 1 | 간 → 담즙 → 육식 소화. 인과가 흐르는 형태 |
| 2 | **화면 확장.** 1단계 내용은 남고, 그 옆/아래로 길항 구도가 열림 |
| 3 | 강한 쪽(간·담낭) ↔ 약한 쪽(폐·대장). 육식이 약한 쪽으로 작용하는 방향 표시 |
| 4 | 반대 방향 — 해물·푸른 잎채소가 이미 강한 쪽을 더 강하게 만드는 흐름 |

**핵심은 2단계입니다.** 1단계를 지우고 2단계로 넘어가면 부정이 되고, 남긴 채 확장하면 보강이 됩니다.

## B-3. 규칙

- **화살표 방향이 논리를 나타냅니다.** 육식 → 약한 쪽(보강) / 해물·잎채소 → 강한 쪽(과잉). 두 방향이 구분되어야 합니다
- 강약을 색으로 표현하되 **"강한 쪽이 좋다"는 인상을 주지 마십시오.** 강한 장기는 과도해지기 쉬운 쪽이지 우수한 쪽이 아닙니다. 강한 쪽에 밝고 긍정적인 색을 쓰면 메시지가 뒤집힙니다
- 육식동물 대장 비유는 **별도 컷으로 분리**하십시오. 이 도식에 넣으면 복잡해집니다
- 개괄편의 과불균형 도식과 **톤 통일**. 기존 컴포넌트가 있으면 재사용하십시오
- 음식 품목 나열은 이 도식이 아니라 **별도 자막**으로 처리합니다

**화면 출처**: `출처: 권도원, 「중환자와 채식」, 빛과소금 1994년 5월호`

# C. Section2c — 온수욕·부교감신경 그래픽

## C-1. 전달해야 하는 것

> 목양·목음은 **부교감신경 긴장체질**이다
> → 속 체온이 겉보다 높다
> → **따뜻한 물**로 땀을 내면 몸이 가벼워진다
> → 냉수욕·수영은 맞지 않는다

## C-2. 연출 구성

| 단계 | 화면 |
|---|---|
| 1 | 속과 겉의 체온 차이 — 몸 단면 또는 동심원 도식. 안쪽이 더 뜨거움 |
| 2 | 따뜻한 물 → 땀 → 열이 풀리는 흐름 |
| 3 | 냉수욕·수영은 맞지 않음 — 대비 표시 |

## C-3. 규칙

- **인체 형상을 쓸 경우 실루엣 수준으로 단순화**하십시오. 해부 도해로 읽히면 의료 정보가 되어 부담이 생깁니다. 개괄편 Section03의 CSS 흉상 방식이 선례입니다
- 온·냉 대비는 색으로 표현하되 **냉수욕을 부정적으로 낙인찍지 마십시오.** 다른 체질에는 맞는 방법입니다. "이 체질에는 맞지 않는다"이지 "나쁜 방법"이 아닙니다
- **수편에서 반대 측면으로 재활용할 그래픽입니다.** 온·냉을 뒤집어 쓸 수 있도록 좌우 또는 색만 교체하면 되는 구조로 설계하십시오. 제작표준 소재 소비 대장에 재활용 계획이 등재되어 있습니다

**화면 출처**: `출처: 권도원, 「체질에 따른 목욕방법」, 빛과소금 1994년 10월호`

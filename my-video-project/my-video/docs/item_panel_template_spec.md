# ItemPanel — 항목별 설명 화면 공통 템플릿 사양서

**용도**: 섹션 3·4의 항목별 설명 화면 (외형 · 성격 · 직업 · 운동 · 질병·건강법)
**첫 적용**: 기본 시리즈 ① 목양·목음편 — 두 섹션 × 5화면 = **10화면**
**재사용**: 금·토·수편에서 데이터만 교체. **이 컴포넌트 하나로 시리즈 전체의 항목 화면을 처리하는 것이 목표**

---

## 1. 왜 템플릿인가

10화면을 개별 설계하면 작업량이 크고, 더 큰 문제는 **섹션 3과 4의 대칭이 깨진다**는 점입니다.

이 편의 뼈대는 **두 체질을 같은 순서·같은 형식으로 나란히 보여주는 것**입니다. 화면마다 연출이 다르면 시청자는 두 체질을 비교하는 대신 화면 차이에 주의를 뺏깁니다. **같은 틀에 내용만 바뀌는 것이 이 편에서는 장점**입니다.

체질별 구분은 **색 하나로** 충분합니다 (`CONSTITUTION_ACCENTS` — 목양 `#7F9E5E`, 목음 `#6FB3A8`).

---

## 2. 인터페이스

```ts
type PanelPoint = {
  text: string;          // 설명 한 줄
  emphasis?: boolean;    // 강조 어구 (핵심 문장 1개 이하)
  note?: string;         // 부기 — 유보 문장, 조건 등
};

type Props = {
  itemLabel: string;        // '외형' | '성격' | '직업' | '운동' | '질병·건강법'
  headline?: string;        // 이 항목의 한 줄 요약. 없으면 생략
  points: PanelPoint[];     // 2~4개 권장
  accentColor: string;      // 체질색
  stageStartsSec?: number[];// 각 point 등장 시각. 미지정 시 균등 분배
};
```

**`emphasis`는 화면당 하나 이하**로 제한하십시오. 둘 이상이면 강조가 아닙니다.

**`note`는 유보·조건 문장 전용**입니다. 직업 항목의 "보편적인 경향일 뿐이며 예외가 있습니다" 같은 것이 여기 들어갑니다. 본문보다 작고 낮은 대비로, 그러나 읽히는 수준으로 처리하십시오.

## 3. 레이아웃

```
┌──────────────────────────────────────┐
│ ▌항목라벨            ← ItemLabel 컴포넌트│
│                                      │
│    headline (있을 때)                  │
│                                      │
│    · point 1                         │
│    · point 2  ← emphasis             │
│    · point 3                         │
│      note (작게)                      │
│                                      │
│                        [출처 자막]     │
├──────────────────────────────────────┤
│  안전 자막 슬롯 (686~895)              │
└──────────────────────────────────────┘
```

- **항목 라벨은 이 컴포넌트가 그리지 않습니다.** 기존 `ItemLabel`을 상위에서 함께 배치하십시오
- 본문 발자국은 **y < 686**(`CONTENT_MAX_Y`)
- 포인트는 순차 등장하고 **사라지지 않습니다.** 항목이 끝날 때 전체가 보여야 합니다
- 등장은 짧은 페이드 + 미세 상승. 화려하게 하지 마십시오 — 10번 반복되는 화면입니다

## 4. 반드시 지켜야 할 규칙

### 대칭

- **섹션 3과 4에서 레이아웃·글자 크기·등장 방식이 완전히 동일해야 합니다.** 다른 것은 색과 내용뿐입니다
- 항목 순서도 동일합니다

### 표현

- **외모를 평가하는 인상을 주지 마십시오.** 외형 항목은 특징 서술이지 미추 판단이 아닙니다. 실루엣을 쓸 경우 **익명의 중립적 형태**로, 특정 인물을 연상시키지 않게 하십시오
- **음치·숨 짧음 등을 조롱조로 그리지 마십시오.** 이 시리즈의 톤이 아닙니다
- **"가장 강한/약한 체질" "선천적으로 튼튼한/약한" 표현 금지.** 배열 위치를 가리키는 "최강장기·최약장기"는 허용되나, 이 화면들에서는 쓸 일이 없습니다
- 강조 표시를 부정적 기호(X, 경고 아이콘)로 하지 마십시오. 안전 경고는 `SafetyCaption`이 담당합니다

### 구조

- 길이를 하드코딩하지 마십시오. `stageStartsSec`로 받으십시오
- 색·폰트는 공통 스타일 재사용
- 화면 출처 자막은 `SourceCaptions` 재사용

## 5. 목양·목음편 데이터

### 섹션 3 — 목양체질 (accent: 목양색)

| 화면 | itemLabel | headline | points |
|---|---|---|---|
| 3-b | 외형 | — | 풍채가 좋고 체구가 큰 편 / 어깨는 좁고 아래로 내려가면서 굵어짐 / **눈사람처럼 허리가 넓어지는 체형** |
| 3-c | 성격 | 말수가 적습니다 | 열 마디에 한두 마디로 답함 / 말하는 것이 에너지를 소모하고 피로를 유발 / 숨이 짧아 노래 한 소절을 넘기기 어려움 / 인자하고 쉽게 용서함, 따지기 싫어함 |
| 3-d | 직업 | — | 툭 터진 넓은 곳, 투기적, 적응적 / 독자 사업이 많고 크게 벌여 성공 / 투자 사업·기계공학·선린주의 정치가 / 세밀한 계산·말 많은 일·예술적인 일은 재고 / 과묵함이 덕으로 보여 선거 당선율이 높음 — **note**: 보편적 경향일 뿐 개인의 환경·학문·여건에 따라 예외가 있음 |
| 3-e | 운동 | 땀을 내는 운동이 맞습니다 | 등산 / 사우나 |
| 3-f | 질병·건강법 | — | 건강할 때 땀이 많고, 땀을 흘리면 몸이 가벼워짐 / 과해진 간의 열이 땀으로 풀림 / **계절과 상관없이 따뜻한 물로 목욕** / 채소·생선 과다, 육식 부족 시 피로·눈 통증·발 답답함 / *(혈압 문단은 SafetyCaption medical과 함께 별도 처리)* |

### 섹션 4 — 목음체질 (accent: 목음색)

| 화면 | itemLabel | headline | points |
|---|---|---|---|
| 4-b | 외형 | — | 팔다리가 길고 손발이 큼 / 근육이 잘 발달 |
| 4-c | 성격 | 감성적입니다 | 조그마한 말에도 쉽게 상처받고 잘 잊히지 않음 / 성질은 급하나 독하지 못함 / 활동적이고 봉사적 |
| 4-d | 직업 | — | 감수성을 함께 고려 / 감정 대립·질투·비판이 잦은 일은 부담 / 술과 거리가 있는 일 *(알코올 문단은 전용 캡션 구간)* / 교육계·기계공학 / **나무와 불을 다루는 일만 빼면 무엇이든** — **note**: 경향성일 뿐 같은 체질 안에서도 예외가 있음 |
| 4-e | 운동 | 이 체질의 특징이 가장 선명하게 드러납니다 | 손으로 던지고 발로 차는 운동에 능함 / **오 년 늦게 시작해도 앞지름** / 공이 생각한 지점에 그대로 감 / 박세리·박찬호·이승엽 `추정` |
| 4-f | 질병·건강법 | — | 대변이 잦은 것 자체는 건강과 무관 / **배꼽 주위 통증이 함께 오면 근제통** / 소화에 지장 없이 하루 몇 번 배변, 항상 배꼽 주위 통증 / 허약해지면 몸이 냉하고 다리가 무겁고 불면 / 원인은 대장의 무력함 / **하복부 보온**, 그리고 절주 |

**4-e의 운동선수 3인은 `추정` 태그와 함께 본문 자막 서식으로** 처리합니다. 인물 타이포 카드 형식을 쓰지 마십시오. `PanelPoint`에 태그를 표시할 수단이 필요하면 `note`를 활용하거나 별도 처리하십시오.

**4-f의 근제통은 자막에 `근제통(近臍痛)` 병기.** 낭독은 뒤 설명 문장이 뜻을 전달합니다.

## 6. 검수 항목

- [ ] 섹션 3과 4의 레이아웃·글자 크기·등장 방식이 동일한가
- [ ] 색만으로 두 체질이 구분되는가
- [ ] 포인트가 순차 등장 후 전체가 남는가
- [ ] `emphasis`가 화면당 하나 이하인가
- [ ] `note`가 본문과 구분되면서도 읽히는가
- [ ] 등장 연출이 과하지 않은가 — **10번 반복되는 화면**
- [ ] 외모 평가·조롱조 인상이 없는가
- [ ] 금지 표현이 없는가
- [ ] 부정적 기호(X, 경고 아이콘)를 쓰지 않았는가
- [ ] y < 686
- [ ] 안전 자막(disclaimer / career / addiction / medical)과 겹치지 않는가
- [ ] 길이가 외부에서 조절 가능한가
- [ ] 포인트가 5개일 때도 레이아웃이 깨지지 않는가

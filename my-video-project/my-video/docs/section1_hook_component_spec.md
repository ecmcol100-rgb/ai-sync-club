# Section1Hook — 후킹 그래픽 컴포넌트 사양서

**용도**: 섹션 1 후킹 — 채식의 역설
**첫 적용**: 기본 시리즈 ① 목양·목음편
**재사용**: 사례 데이터가 편마다 다르므로 **구조만 재사용**. 수치 카운트업과 항목 예고는 전 편 공통

---

## 1. 이 구간의 성격

**첫 10초 이탈 방어 구간**입니다. 시청자가 계속 볼지 말지를 결정하는 자리입니다.

두 개의 서로 다른 목표가 한 섹션에 있습니다.

| 구간 | 목표 | 성격 |
|---|---|---|
| 사례 두 건 (1-a) | **놀라게 하기** | 반전. 숫자가 주인공 |
| 항목 예고 (1-b) | **시청 지속 약속** | 앞으로 볼 것을 미리 보여줌 |

두 구간의 연출 톤이 달라야 합니다. 앞은 극적으로, 뒤는 정돈되게.

---

## 2. 1-a 채식의 역설

### 전달해야 하는 것

> 채식이 몸에 좋다는 상식 → **그런데 두 사람은 채식으로 나빠졌다** → 두 사람은 같은 체질이었다

### 구성

| 단계 | 화면 | 대응 내레이션 |
|---|---|---|
| 1 | "채식은 몸에 좋다" — 통념 제시 | 채식이 몸에 좋다는 말… |
| 2 | 사례 ① — 일 년 채식 → 극심한 피로 → 육식 복귀 후 회복 | 어느 환자분은… |
| 3 | 사례 ② — **콜레스테롤 수치 카운트업** | 또 다른 한 분은… |
| 4 | 두 사례가 한 화면에 모이고 → **"목양체질"** 등장 | 두 사람은 같은 체질이었습니다 |

### 수치 카운트업 — 이 화면의 핵심

```
400+  ──[한 달 채식]──▶  1,700  ──[한 달 육식]──▶  400
```

**규칙**

- **`1,700` 도달 후 최소 0.8초 유지.** 이 숫자가 이 구간에서 가장 강한 순간입니다. 바로 다음 단계로 넘어가면 효과가 사라집니다
- **첫 수치는 `400+` 또는 `400↑`로 표기.** 내레이션이 "사백이 넘게 나와"이므로 정확히 400으로 쓰면 어긋납니다
- 카운트업은 **선형이 아니라 감속 곡선**으로. 목표값 근처에서 느려져야 도달감이 생깁니다
- 400 → 1,700 상승과 1,700 → 400 하강의 **속도를 다르게** 하십시오. 상승은 놀라움, 하강은 회복입니다
- 수치 옆에 단위(mg/dL)를 붙일지는 판단 사항입니다. **붙이지 않기를 권합니다** — 의학 검사 수치로 정밀하게 읽히면 부담이 생기고, 원자료에도 단위가 명시되어 있지 않습니다

### 주의

- **"치료" "완치" 등 효과 단정 표현 금지**
- **사례 인물의 직업·신분을 밝히지 마십시오.** "환자분"으로만. 원자료에는 직업이 있으나 특정 직군을 밝히면 권위에 기대는 인상과 개인 식별 가능성이 생깁니다
- 채식·육식을 **선악으로 그리지 마십시오.** 이 편의 주장은 "채식이 나쁘다"가 아니라 "체질에 따라 다르다"입니다. 채식 이미지에 부정적 색·기호를 쓰면 메시지가 왜곡됩니다
- 실제 인물 사진·일러스트 사용 금지 (시리즈 공통)

**화면 출처**: `출처: 권도원, 「중환자와 채식」, 빛과소금 1994년 5월호`

## 3. 1-b 항목 예고

### 전달해야 하는 것

> 오늘 이 아홉 가지를 다룹니다 — **시청 지속 약속**

### 구성

내레이션에 맞춰 항목이 순차 등장하고, 마지막에 전체가 한 화면에 정렬됩니다.

```
장기 배열 → 외형 → 성격 → 직업 → 운동 → 질병 → 음식 → 건강법
```

*(내레이션은 유명인을 언급하지 않으므로 8개가 등장합니다. 9항목 중 유명인은 예고에서 제외)*

### 규칙

- **명칭을 유튜브 챕터·항목 라벨과 통일**하십시오. 같은 것을 다르게 부르면 시청자가 연결하지 못합니다
- 아이콘을 쓸 경우 **항목 라벨(ItemLabel)에서 재사용 가능한 형태**로 만드십시오. 지금은 라벨이 텍스트만 쓰지만 아이콘이 생기면 양쪽에서 씁니다
- 등장 리듬을 내레이션 낭독 속도에 맞추십시오. 쉼표마다 하나씩입니다
- **등장한 항목은 사라지지 않습니다.** 마지막에 전체가 보여야 "이만큼 다룬다"가 전달됩니다

---

## 4. 공통 규칙

- **길이를 하드코딩하지 마십시오.** 단계 시작 시각을 props로 받으십시오 (`stageStartsSec`). 오디오 확보 후 조정합니다
- 본문 그래픽은 **y < 686**(`CONTENT_MAX_Y`) 안에서 끝날 것
- 색·폰트는 공통 스타일 재사용. 목양체질 등장 시 `CONSTITUTION_ACCENTS`의 목양 색 사용
- 이 구간에는 disclaimer 자막이 **아직 뜨지 않습니다**(섹션 3부터). 하단 여유가 있으나 자막 안전 영역(920~)은 침범하지 마십시오

## 5. 검수 항목

### 1-a

- [ ] `1,700` 도달 후 0.8초 이상 유지되는가
- [ ] 첫 수치가 `400+` 형태로 표기되는가
- [ ] 카운트업이 감속 곡선인가 — 선형이면 도달감이 없음
- [ ] 상승과 하강의 속도가 구분되는가
- [ ] 채식이 부정적으로 그려지지 않는가 — **"체질에 따라 다르다"이지 "채식이 나쁘다"가 아님**
- [ ] 사례 인물의 직업·신분이 노출되지 않는가
- [ ] 인물 사진·일러스트가 없는가
- [ ] 효과 단정 표현이 없는가
- [ ] 마지막에 "목양체질"이 강조되는가

### 1-b

- [ ] 8개 항목이 순차 등장 후 전체가 남는가
- [ ] 명칭이 챕터·항목 라벨과 일치하는가
- [ ] 아이콘이 ItemLabel에서 재사용 가능한 형태인가

### 공통

- [ ] 길이가 외부에서 조절 가능한가
- [ ] y < 686
- [ ] 화면 출처 자막이 있는가
- [ ] **첫 10초 안에 "왜 계속 봐야 하는가"가 전달되는가** — 최종 판단 기준

---

## 6. 판단이 필요한 것

**채식 이미지를 어떻게 표현할지**는 정해져 있지 않습니다. 사진은 쓸 수 없고(저작권), 인물도 안 됩니다. 세 가지 방향이 있습니다.

- 타이포그래피만으로 — 시리즈 톤과 일관되나 첫 화면치고 밋밋할 수 있음
- 채소·고기의 단순 도형 아이콘 — 직관적이나 새 에셋이 필요
- 수치 카운트업으로 바로 진입 — 가장 강렬하나 통념 제시 단계가 사라짐

**구현 시 판단하고, 결과를 보고 조정하겠습니다.**

# OrganArrayTransition — Remotion 컴포넌트 사양서

**용도**: 8체질 영상 시리즈 섹션 2 장기 강약 배열 화면 (2-a)
**첫 적용**: 기본 시리즈 ① 목양·목음편
**재사용**: 금·토·수편에서 데이터만 교체 — **컴포넌트 로직은 수정하지 않는 것을 목표로 설계할 것**

---

## 1. 이 화면이 전달해야 하는 것

> 두 체질은 **양 끝(1번·5번)이 같고, 가운데 세 칸이 서로 자리를 바꾼다.**

이것이 전부입니다. 시청자가 보고 난 뒤 **"가운데가 다르구나"**가 남으면 성공이고, 어느 장기가 몇 번인지 외우게 하는 것이 목적이 아닙니다.

판단 기준은 "이동을 다 봤는가"가 아니라 **"보고 난 뒤 두 번째 배열이 머리에 남는가"**입니다.

---

## 2. 데이터 구조

4편 공통으로 쓰기 위해 **배열 데이터를 props로 분리**합니다.

```ts
type OrganCell = {
  id: string;        // 'liver' | 'kidney' | ... — 이동 추적 키
  labelA: string;    // 체질 A에서의 표기 (주도 장부를 앞에)
  labelB: string;    // 체질 B에서의 표기
};

type Props = {
  constitutionA: string;   // '목양체질'
  constitutionB: string;   // '목음체질'
  cells: OrganCell[];      // 길이 5. 체질 A 기준 1→5 순서
  orderB: string[];        // 체질 B의 순서를 id 배열로. 길이 5
  fixedCells: string[];    // 이동하지 않는 칸의 id (보통 1번·5번)
  liftDown: string[];      // 아래로 움직일 칸의 id
  caption?: string;        // 첫 칸 아래 소형 캡션
};
```

### 목양·목음편 데이터

```ts
const mokProps: Props = {
  constitutionA: '목양체질',
  constitutionB: '목음체질',
  cells: [
    { id: 'liver',    labelA: '간·담낭',   labelB: '담낭·간'   },
    { id: 'kidney',   labelA: '신장·방광', labelB: '방광·신장' },
    { id: 'heart',    labelA: '심장·소장', labelB: '소장·심장' },
    { id: 'pancreas', labelA: '췌장·위장', labelB: '위장·췌장' },
    { id: 'lung',     labelA: '폐·대장',   labelB: '대장·폐'   },
  ],
  orderB: ['liver', 'heart', 'pancreas', 'kidney', 'lung'],
  fixedCells: ['liver', 'lung'],
  liftDown: ['kidney'],
  caption: '간·담낭 = 木 → 목(木)체질',
};
```

**주의**: 체질 A는 장(臟)이 주도하므로 다섯 칸 모두 장이 앞에, 체질 B는 부(腑)가 주도하므로 **다섯 칸 모두 부가 앞에** 옵니다. 따라서 1번·5번 칸은 이동하지 않아도 표기가 바뀝니다(간·담낭 → 담낭·간, 폐·대장 → 대장·폐). 이동과 표기 전환을 별개로 처리하십시오.

## 3. 애니메이션 시퀀스

**총 5.3초.** 프로토타입으로 검증된 값입니다.

| 단계 | 시각 | 동작 | 길이 |
|---|---|---|---|
| 0 | 0.00 | 체질 A 배열 5칸 제시. 1·5번 칸을 고정색으로 표시 | 1.00초 |
| 1 | 1.00 | 2·3·4번 칸 동시 강조색 점등 (이동 예고) | 0.50초 |
| 2 | 1.50 | `kidney` **아래로** → 2번에서 4번으로 → 제자리 높이 복귀 | 0.95초 |
| 3 | 2.45 | `heart` **위로** → 3번에서 2번으로 → 복귀 | 0.95초 |
| 4 | 3.40 | `pancreas` **위로** → 4번에서 3번으로 → 복귀 | 0.95초 |
| 5 | 4.35 | 1·5번 칸 표기 전환. 상단 체질명 A → B 전환. 강조색 유지한 채 정지 | 0.95초 |

**각 이동의 내부 분해** (0.95초)

```
0.00 ~ 0.20   들어올림/내려놓음 (수직 이동 시작)
0.20 ~ 0.67   수평 이동 (0.47초, cubic-bezier(0.4, 0, 0.2, 1))
0.67 ~ 0.95   원래 높이로 복귀
```

수직 이동 폭은 **카드 높이의 90% 안팎**(프로토타입 기준 52px / 카드 높이 56px).

30fps 기준 프레임: 단계 0=0~30, 1=30~45, 2=45~73, 3=73~102, 4=102~130, 5=130~159.

## 4. 반드시 지켜야 할 규칙

이 규칙들은 프로토타입에서 실패를 확인하고 정한 것입니다. **구현 편의를 이유로 바꾸지 마십시오.**

### 이동 방식

- **세 칸을 동시에 움직이지 않습니다.** 2→4 / 3→2 / 4→3은 순환 이동이라 경로가 교차합니다. 반드시 순차 진행
- **수평 이동 금지.** 같은 높이에서 지나가면 중간 칸과 겹쳐 무슨 일이 일어나는지 읽히지 않습니다
- **이동 방향을 나눕니다.** `kidney`는 아래로, 나머지 둘은 위로. 셋을 같은 방향으로 보내면 경로가 겹쳐 "누가 어디로 갔는지"가 흐려집니다. 방향을 나누면 *두 칸을 건너가는 하나* vs *한 칸씩 당겨지는 둘*이라는 성격 차이가 드러납니다
- **가장 멀리 가는 칸을 먼저** 움직입니다. 시선을 끌고, 그 자리가 비어야 나머지가 자연스럽게 풀립니다
- 이동 중인 칸은 **다른 칸 위에 그립니다**(z-index)

### 길이

- **5.3초를 줄이지 마십시오.** 2배속(4.0초)을 검토했으나 이동당 0.35초로 떨어져 인지 시간이 부족합니다. 곡선 이동으로 확보한 가독성을 상쇄합니다
- 내레이션(약 5초)과 거의 일치하므로 **여백 없이 붙입니다**

### 표시

- **두 배열을 위아래로 놓고 비교하지 않습니다.** 어느 칸이 어디로 갔는지 눈이 따라가지 못합니다. 한 줄이 변형되는 방식이며, 대조 정지 화면은 변형이 끝난 뒤에만
- **이동 단계별 자막을 넣지 않습니다**("신장·방광 : 2 → 4" 같은 라벨). 프로토타입에서는 검증용으로 표시했으나 실제 화면에는 넣지 않습니다
- 순위는 **1~5 숫자로만** 표기. **"최강/최약" 문구를 쓰지 않습니다**
- **오행 표기(木〉水〉火〉土〉金)를 노출하지 않습니다.** 초급 시청자에게 장벽이 되고, 오행 상생상극 이론으로 오독될 소지가 있으며, 전통 오행 의학의 한 갈래로 읽힐 위험이 있습니다
- 1번 칸은 **주도 장부를 앞에** 표기합니다. 화면에서 왼쪽이 더 강한 것으로 읽히므로, 섹션 3·4의 "간이 강한 체질 / 담낭이 강한 체질"과 어긋나면 안 됩니다
- 교감·부교감신경 2기관은 이 다이어그램에서 제외합니다(별도 자막 처리)

## 5. 레이아웃

프로토타입 기준값입니다. 실제 해상도에 맞게 비례 조정하십시오.

| 요소 | 값 |
|---|---|
| 카드 너비 | 104 (기준) |
| 카드 높이 | 56 |
| 카드 간격 | 12 |
| 수직 이동 폭 | 52 |
| 모서리 반경 | 8 |

**구성**
```
[상단]  체질명 (목양체질 → 목음체질로 전환)
[중앙]  5칸 가로 배열
[하단]  1 2 3 4 5 순위 숫자
[캡션]  1번 칸 아래 소형 — "간·담낭 = 木 → 목(木)체질"
[출처]  화면 하단 — "출처: 생기능의학 교재(2008) / 「8체질의학론 개요」(2003)"
```

**색 처리 3종**
- 고정 칸(1·5번): 양 끝이 같다는 것을 먼저 보여주는 색
- 이동 칸(2·3·4번): 단계 1에서 점등되는 강조색. 끝까지 유지
- 기본: 나머지

색상 토큰은 시리즈 공통 스타일 컴포넌트를 따르십시오. 이 컴포넌트에서 색을 새로 정의하지 마십시오.

## 6. 다른 편 적용 예시

금양·금음편은 데이터만 바꾸면 됩니다.

```ts
// 금양: 폐·대장 > 췌장·위장 > 심장·소장 > 신장·방광 > 간·담낭
// 금음: 대장·폐 > 방광·신장 > 위장·췌장 > 소장·심장 > 담낭·간
```

**단, 편마다 확인할 것**
- 이동하는 칸이 몇 개인지 (목·목음편은 3개이나 다른 체질군은 다를 수 있음)
- `liftDown`에 넣을 칸 — 가장 멀리 이동하는 칸을 아래로
- 1·5번 칸이 정말 고정인지 — 체질군에 따라 다를 수 있음

**배열 데이터는 반드시 생기능의학 교재(2008) 표1 원본과 대조한 뒤 입력하십시오.** 기억이나 추론으로 넣지 마십시오.

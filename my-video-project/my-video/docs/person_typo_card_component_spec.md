# PersonTypoCard — 인물 타이포 카드 컴포넌트 사양서

**용도**: 8체질 영상 시리즈 인물 소개 구간
**첫 적용**: 기본 시리즈 ① 목양·목음편 (섹션 3-g, 4-g)
**재사용**: 전 시리즈 공통. **인물 데이터와 체질 정보만 편별로 주입**하고 컴포넌트는 수정하지 않는 것을 목표로 설계할 것

---

## 1. 이 컴포넌트의 전제 — 사진을 쓰지 않습니다

**모든 인물은 사진·실루엣 없이 타이포그래피만으로 표현합니다.**

이것은 디자인 선택이 아니라 **제작 방침**입니다. 초상권과 저작권 문제를 원천적으로 피하기 위한 것이며, 다음이 전면 금지됩니다.

- 사진, 실루엣, 초상 일러스트, AI 생성 인물 이미지
- 인물을 연상시키는 소품이나 배경 (기업 로고, 관공서 건물 등)

**이 제약을 우회하지 마십시오.** "실루엣이면 괜찮지 않나" 같은 판단을 하지 말고, 타이포그래피만으로 화면을 채우는 방향으로 설계하십시오.

**대신 시각적 밀도를 보완합니다.** 사진이 빠지면 인물 구간이 정지 화면처럼 느껴지므로 두 가지를 씁니다.
1. 배경에 **해당 체질의 장기 실루엣**을 저채도로 크게 배치 (목양=간, 목음=담낭)
2. **타이포 애니메이션에 리듬**을 실어 등장 자체가 볼거리가 되게 함

---

## 2. 컴포넌트 인터페이스

```ts
type Person = {
  name: string;        // '이병철'
  title?: string;      // '삼성 창업주' — 이름 위 또는 앞에 소형 배치
};

type Props = {
  constitution: string;      // '목양체질'
  constitutionSub: string;   // '木陽 · Hepatonia'
  people: Person[];          // 최대 3인 권장
  organSilhouette: string;   // 배경 실루엣 에셋 키 ('liver' | 'gallbladder' | ...)
  accentColor?: string;      // 미지정 시 체질 시그니처 컬러 사용
};
```

**`추정` 태그 prop을 두지 마십시오.** 추정 등급 인물은 이 카드에 넣지 않습니다(4절 참조).

### 목양·목음편 데이터

```tsx
// 섹션 3-g
<PersonTypoCard
  constitution="목양체질" constitutionSub="木陽 · Hepatonia"
  organSilhouette="liver"
  people={[
    { title: '삼성 창업주', name: '이병철' },
    { title: '전 대통령',   name: '전두환' },
    { name: '육영수' },
  ]}
/>

// 섹션 4-g
<PersonTypoCard
  constitution="목음체질" constitutionSub="木陰 · Cholecystonia"
  organSilhouette="gallbladder"
  people={[
    { title: '전 대통령', name: '김영삼' },
    { title: '회장',      name: '이건희' },
    { title: '철학자',    name: '김용옥' },
  ]}
/>
```

## 3. 레이아웃과 연출

### 구성

```
[상단]   체질명 고정 노출 — "목양체질(木陽 · Hepatonia)"
[중앙]   인물 1행씩 세로 배치
           수식어(소)
           이름(대)
[배경]   장기 실루엣, 저채도, 크게
[하단]   디스클레이머 자막 유지 (SafetyCaption)
```

### 등장 시퀀스

| 단계 | 동작 |
|---|---|
| 0 | 체질명 + 배경 실루엣 먼저 표시 |
| 1 | 1인 페이드인 + 미세 상승 |
| 2 | 약 1.5초 뒤 2인 |
| 3 | 약 1.5초 뒤 3인 |
| 4 | 3인이 함께 정렬된 상태로 잔상 유지 |

- 등장한 인물은 **사라지지 않고 남습니다.** 마지막에 3인이 함께 보이는 구도가 되어야 합니다
- 1.5초 간격은 내레이션의 이름 낭독과 맞물립니다. 대본에 이름 뒤 쉼(`…`)이 지정되어 있으므로 **실측 오디오에 맞춰 조정**하십시오
- 등장 간격은 props나 Sequence로 조절 가능하게 하고, 컴포넌트에 하드코딩하지 마십시오

### 좌표 제약

**본문 그래픽은 y < 686 안에서 끝나야 합니다** (`CONTENT_MAX_Y`). 배경 실루엣과 3행 인물 텍스트를 모두 포함한 발자국이 이 범위를 넘지 않는지 확인하십시오. 하단에는 disclaimer 자막이 상시 떠 있습니다.

## 4. 반드시 지켜야 할 규칙

### 인물 등급

- **추정 등급 인물을 이 카드에 넣지 마십시오.** A급(직접 진맥)과 학회 확인 인물만 들어갑니다
- 추정 인물은 해당 항목의 **본문 자막 서식**으로 처리하고 `추정` 태그를 병기합니다. 카드 형식을 쓰지 않습니다
- 이유: 근거 등급이 다른 인물이 같은 카드에 섞이면 시청자가 신뢰도를 구분하지 못합니다. 그리고 인물 카드가 한 섹션에 두 번 등장하면 섹션 간 대칭이 깨집니다

### 시각

- 사진·실루엣·초상 일러스트·AI 생성 인물 이미지 **전면 금지**
- 인물을 연상시키는 소품·배경 **금지**
- 배경 장기 실루엣은 **저채도**로. 인물 텍스트 가독성을 해치면 안 됩니다
- 체질 시그니처 컬러를 쓰되 **개괄편 체질 컷 톤과 통일**할 것. 색을 새로 정의하지 말고 공통 스타일을 재사용하십시오

### 구조

- 등장 간격·타임코드를 컴포넌트에 하드코딩하지 마십시오
- 인물 수는 3인 기준이나 **2인 또는 4인도 깨지지 않게** 설계하십시오. 다른 편에서 인원이 달라집니다
- `title`이 없는 인물(예: 육영수)도 레이아웃이 흐트러지지 않아야 합니다

---

## 5. 검수 항목

- [ ] 사진·실루엣·초상 이미지가 전혀 없는가
- [ ] 인물 연상 소품·배경이 없는가
- [ ] 체질명이 상단에 고정 노출되는가
- [ ] 3인이 순차 등장 후 함께 남는가
- [ ] 등장 애니메이션에 리듬이 있는가 — **정지 화면처럼 느껴지면 실패**
- [ ] 배경 실루엣이 텍스트 가독성을 해치지 않는가
- [ ] `title` 없는 인물에서 레이아웃이 흐트러지지 않는가
- [ ] 2인·4인일 때도 구도가 유지되는가
- [ ] 발자국이 y < 686 안에서 끝나는가
- [ ] disclaimer 자막과 겹치지 않는가
- [ ] 등장 간격이 외부에서 조절 가능한가

|---|---|

### 섹션 4-g 목음체질

| 표기 | 근거 등급 |
|---|---|
| 전 대통령 / 김영삼 | 학회 확인 |
| 회장 / 이건희 | A급 — 직접 진맥 |
| 철학자 / 김용옥 | 학회 확인 |

| 인물 | 처리 |
|---|---|
| 박세리 · 박찬호 · 이승엽 | 추정 등급. **섹션 4 운동 항목 내 본문 자막 + `추정` 태그.** 카드 형식 사용하지 않음 |

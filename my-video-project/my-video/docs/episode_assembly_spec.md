# MokEpisode — 편 본체 조립 사양서

**용도**: 목양·목음편 전체 조립 (섹션 0~6)
**전제**: 컴포넌트 17종 완성. **오디오는 나중에 확보**하므로 임시 길이로 배선
**총 길이**: 낭독 639초 + 무음 28초 = **약 11분 07초** (5.5자/초 환산)

---

## 1. 조립 원칙

**모든 길이는 상수에서 옵니다.** 컴포넌트에 프레임 수를 직접 쓰지 마십시오.

```ts
// timing.ts — 오디오 확보 후 이 파일만 교체하면 됨
export const FPS = 30;
export const SEC = (s: number) => Math.round(s * FPS);

export const SECTION_STARTS_SEC = { s0: 0, s1: 8, s2: 56, s3: 192, s4: 395, s5: 607, s6: 653 };
export const SECTION_LENGTHS_SEC = { s0: 8, s1: 48, s2: 136, s3: 203, s4: 212, s5: 45, s6: 14 };
```

*※ 섹션 4는 낭독 192초 + 대조표 무음 20초 = 212초*

**오디오 확보 후 절차**: 섹션별 오디오 파일을 `public/audio/`에 넣고, `calculateMetadata` + `getAudioDurationInSeconds`로 실제 길이를 읽어 위 상수를 대체합니다. 문단 단위 구간은 **섹션 길이를 글자 수 비율로 나눠** 산출하십시오(같은 음성·설정이라 섹션 안에서 속도가 일정합니다).

## 4. 화면 전환

- 기본은 **짧은 크로스페이드**(0.3~0.4초). 컴포넌트마다 자체 페이드가 있으므로 전환을 겹쳐 넣지 마십시오
- **섹션 경계**는 조금 길게(0.6초) — 큰 단락이 바뀐다는 신호
- **혈압 구간 진입·이탈**은 더 느리게(0.8초). 이 구간은 다른 곳보다 리듬이 느립니다
- **대조표 진입 시 전환 없이 즉시 정지 화면**으로. 스크린샷 대상이므로 페이드 중 촬영되면 곤란합니다

## 5. 검수 항목

### 배선

- [ ] 모든 길이가 `timing.ts` 상수에서 오는가 — 하드코딩 없음
- [ ] 자막 4종의 구간이 정확한가, 특히 `career`가 알코올 문단을 비켜 두 구간으로 나뉘는가
- [ ] `medical` 구간과 출처 `raisedRanges`가 같은 값인가
- [ ] 대조표 20초가 무음인가
- [ ] 섹션 5·6에 disclaimer가 뜨지 않는가

### 전체

- [ ] 총 길이가 약 11분 07초인가
- [ ] 유튜브 챕터 지점이 섹션 시작과 일치하는가
- [ ] 컴포넌트 발자국이 모두 y < 686인가 — **합성 상태에서 재확인**
- [ ] 자막과 본문이 어느 구간에서도 겹치지 않는가
- [ ] 체질 칩이 4곳에만 쓰이는가
- [ ] 출처 자막이 어느 화면에서도 두 줄이 되지 않는가

### 흐름

- [ ] 섹션 3과 4의 항목 순서·형식이 대칭인가
- [ ] 4-i "반대 체질"과 섹션 6 클로징이 연결되는가
- [ ] 섹션 1 항목 예고와 `ItemLabel` 명칭이 일치하는가
- [ ] **처음부터 끝까지 재생했을 때 끊기거나 튀는 곳이 없는가**

## 6. 오디오 확보 후 할 일

5. 유튜브 챕터 재계산
6. 전체 재생 확인 후 최종 렌더

## 1. 조립 원칙

**모든 길이는 상수에서 옵니다.** 컴포넌트에 프레임 수를 직접 쓰지 마십시오.

```ts
// timing.ts — 오디오 확보 후 이 파일만 교체하면 됨
export const FPS = 30;
export const SEC = (s: number) => Math.round(s * FPS);

export const SECTION_STARTS_SEC = { s0: 0, s1: 8, s2: 56, s3: 192, s4: 395, s5: 607, s6: 653 };
export const SECTION_LENGTHS_SEC = { s0: 8, s1: 48, s2: 136, s3: 203, s4: 212, s5: 45, s6: 14 };
```

*※ 섹션 4는 낭독 192초 + 대조표 무음 20초 = 212초*

**오디오 확보 후 절차**: 섹션별 오디오 파일을 `public/audio/`에 넣고, `calculateMetadata` + `getAudioDurationInSeconds`로 실제 길이를 읽어 위 상수를 대체합니다. 문단 단위 구간은 **섹션 길이를 글자 수 비율로 나눠** 산출하십시오(같은 음성·설정이라 섹션 안에서 속도가 일정합니다).

# 부록 A. 조립 구현 기록 (2026-08-27 — 인수인계용)

조립은 `src/MokEpisode/`에 완료됨. 컴포지션 `MokEpisode`, 20,010프레임 = 667초 = 11:07 정확.

## A-1. timing.ts 실제 구조

모든 시각의 단일 원천. 조립부(index.tsx)에는 프레임 직접 기입이 0곳이다.

| 상수 | 내용 |
|---|---|
| `FPS`, `SEC(s)` | 30fps, 초→프레임 반올림 변환 |
| `SECTION_STARTS_SEC` / `SECTION_LENGTHS_SEC` | 섹션 s0~s6 시작·길이(초) — 본 사양서 1절 표 그대로 |
| `TOTAL_SEC` / `TOTAL_FRAMES` | 667 / 20010 — 파생값 |
| `S1_STAGES_SEC`, `S1_ITEM_INTERVAL_SEC` | 섹션1 5단계 시각, 예고 8개 간격(1.1초 — 마지막 항목 등장 후 0.33초 여유) |
| `S2` (객체) | intro/organPresent/organAnim/organEnd/bile/bileExpand/bileEnd/carnivore/food/bathing/bridge/end |
| `ORGAN_FREEZE_FRAME` (=25) | 2-a 정지 제시에 쓰는 컴포넌트 내부 프레임 — 등장 완료 직후·강조 점등 직전 |
| `S2B_STAGES_SEC`, `CARNIVORE_STAGES_SEC`, `FOOD_STAGES_SEC`, `S2C_STAGES_SEC` | 각 컴포넌트에 넘기는 단계 시각(컴포넌트 상대초) |
| `S3` / `S4` (객체) | 화면 전환 시각 — 본 사양서 2절 표 그대로 |
| `S3_CAPTIONS` / `S4_CAPTIONS` | 자막 구간. career는 알코올 문단을 비켜 career1/addiction/career2 세 구간 |
| `S4_D_POINTS_SEC` | 4-d 포인트 등장 — 3번째(술)가 알코올 문단 시작(패널 상대 24.5초)과 맞물림 |
| `TABLE_SKIP_FADE_FRAMES` (=15) | 대조표 내부 페이드인을 건너뛰는 오프셋 |
| `S5_STAGES_SEC` | 자가진단 5단계 |
| `YOUTUBE_CHAPTERS` | 섹션 상수에서 파생 — 지점 불일치가 구조적으로 불가능 |

모든 값이 0.1초 단위이므로 `SEC()` 반올림에서 인접 구간의 끝프레임 = 다음 시작프레임이 정확히 일치한다(1프레임 틈·겹침 없음). **값을 바꿀 때도 0.1초 단위를 유지할 것.**

## A-2. 임시 길이 배선과 오디오 교체 절차

현재 값은 5.5자/초 환산 임시 길이다. 오디오 확보 후:

1. 섹션별 오디오를 `public/audio/`에 배치
2. `calculateMetadata` + `getAudioDurationInSeconds`(@remotion/media-utils, 설치됨)로 실측 → `SECTION_LENGTHS_SEC` 교체, `SECTION_STARTS_SEC`는 누적합으로 재계산
3. 문단·자막·단계 시각(S1~S5 상수)을 섹션 길이의 글자 수 비율로 재분배 — 혈압 구간만 5~8% 감속이라 비례에서 벗어남 (본 사양서 6절)
4. `<Audio>` 트랙을 index.tsx에 추가 (대조표 20초는 무음 공백 유지)
5. `YOUTUBE_CHAPTERS`는 자동 파생되므로 값만 확인
6. 전체 렌더 후 경계 검사 재실행 (아래 A-4 방법)

## A-3. 조립 과정에서 내린 판단과 이유

1. **2-a 3문단 배선** — 컴포넌트의 5.3초 타임라인은 2a 사양서상 수정 불가.
   ① 양 끝 제시(25.3초)는 `<Freeze frame={25}>` 정지, ② 이동부터는 **음수 오프셋
   중첩 Sequence**(`<Sequence from={-25}>`)로 같은 프레임에서 이어붙여 이음새 없음.
   애니 종료 후 최종 상태가 ③ 결론까지 자연 유지된다.
2. **대조표 진입** — "전환 없이 즉시 정지 화면"(4절)을 위해 내부 페이드인
   15프레임을 음수 오프셋으로 건너뜀.
3. **4-d 패널 연속** — 세 문단(전반/알코올/후반)에 패널 Sequence를 나누면
   포인트 애니메이션이 재시작되므로 패널은 하나로 연속시키고 자막만 교체.
   라벨(직업)도 하나로 유지.
4. **4-i 정답+예고 [가안]** — 전용 컴포넌트가 없어 EmphasisCaption 2연으로 배선.
   문안("가장 가까운 체질은 수음체질" / "목과 반대인 금 — 다음 편에서")은
   편 스펙 v5 28·30·31항에서 파생한 초안. **원장님 확정 필요.**
5. **섹션 2 도입 칩** — 칩 사용처는 원칙적으로 4곳 한정이나, 본 사양서 2절이
   "도입(ConstitutionName 2개 제시)"을 명시하여 예외로 적용. 총 5곳째.
6. **전환 문장(상대 131.7~136)** — 내레이션만 있는 구간이라 화면 공백으로 둠.
7. **전환 이중화 방지** — 컴포넌트 자체 페이드만 쓰고 조립부 크로스페이드는
   얹지 않음(4절). 혈압 구간의 느린 리듬은 컴포넌트 내장 0.8초 페이드가 담당.

## A-4. 전체 재생 검증 방법 (재실행용)

렌더된 mp4에서 구간 경계(+1초) 프레임을 Remotion 내장 ffmpeg
(`node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe`)로 PNG 추출 후
휘도 측정(max>100 = 내용 있음). 주의: 이 ffmpeg는 트림 빌드라 `-f null`·
pgm·bmp 인코더가 없음 — **PNG로 뽑아야 한다.** 2026-08-27 검증 결과:
경계 30곳 전부 정상, 유일한 공백은 의도된 전환 문장 구간(188.7초).

# SafetyCaption — 자막 컴포넌트 사양서

**용도**: 8체질 영상 시리즈 안전·고지 자막 4종
**첫 적용**: 기본 시리즈 ① 목양·목음편
**재사용**: 전 시리즈 공통. **문구와 노출 구간만 편별로 지정**하고 컴포넌트는 수정하지 않는 것을 목표로 설계할 것

---

## 1. 왜 4종으로 나누는가

네 자막은 **경고 강도와 노출 방식이 서로 다릅니다.** 하나로 합치면 강도 구분이 사라지고, 시청자는 모든 자막을 같은 무게로 읽게 됩니다. 가장 중요한 의료 경고가 일반 고지문과 같아 보이면 안 됩니다.

| 종류 | 강도 | 노출 방식 | 목적 |
|---|---|---|---|
| `disclaimer` | 1 (기본) | 섹션 전체 상시 | 경향임을 알림 |
| `medical` | **4 (최상위)** | 특정 구간 고정 | 복약 중단 방지 |
| `career` | 2 | 특정 구간 고정 | 진로 단정 방지 |
| `addiction` | 3 | 특정 문단만, `career`와 **교체** | 치료 필요성 고지 |

**시인성 순서를 반드시 지키십시오**: `medical` > `addiction` > `career` > `disclaimer`

---

## 2. 컴포넌트 인터페이스

```ts
type CaptionKind = 'disclaimer' | 'medical' | 'career' | 'addiction';

type Props = {
  kind: CaptionKind;
  text: string;           // 문구는 편별로 주입. 컴포넌트에 하드코딩하지 말 것
  fadeInFrames?: number;  // 기본 8
  fadeOutFrames?: number; // 기본 8
};
```

**노출 구간은 컴포넌트가 아니라 상위 Sequence가 제어합니다.** `<Sequence from={...} durationInFrames={...}>` 안에 배치하십시오. 컴포넌트 내부에 타임코드를 넣지 마십시오 — 실측 길이가 확정되면 전부 바뀝니다.

### 목양·목음편 적용 예시

```tsx
// 섹션 3~4 전체
<Sequence from={S3_START} durationInFrames={S4_END - S3_START}>
  <SafetyCaption kind="disclaimer"
    text="일반적인 체질별 경향을 설명한 것으로, 절대적인 특성이 아닙니다." />
</Sequence>

// 섹션 3 혈압 구간
<Sequence from={BP_START} durationInFrames={BP_LEN}>
  <SafetyCaption kind="medical"
    text="복용 중인 혈압약을 임의로 중단하지 마시고 반드시 담당 의사와 상의하십시오." />
</Sequence>

// 섹션 3 직업 구간 / 섹션 4 직업 구간 (알코올 문단 제외하고 둘로 나눔)
<SafetyCaption kind="career"
  text="직업 적성은 경향이며, 진로 판단의 근거가 아닙니다." />

// 섹션 4 알코올 문단
<SafetyCaption kind="addiction"
  text="알코올 의존은 전문적인 치료가 필요한 문제입니다." />
```

## 3. 종류별 규격

### disclaimer — 고정 디스클레이머

- 반투명 검정 배경 바
- 흰색 텍스트, 소형
- 화면 하단. **자막 안전 영역(하단 160px) 위**에 배치
- 섹션 3~4 내내 상시 노출. 다른 자막이 떠도 사라지지 않음

### medical — 의료 경고 (최상위)

- **붉은 계열 아이콘 + 반투명 배경 바**
- 다른 자막보다 **큰 글자, 높은 대비**
- 구간 전체 고정. 페이드 인/아웃 외에 움직임 없음
- `disclaimer`와 동시 노출되므로 **세로로 겹치지 않게** 배치

이 자막은 이 시리즈에서 **가장 중요한 안전장치**입니다. 시각적으로 확실히 구분되어야 하며, 다른 자막과 비슷해 보이면 실패입니다.

### career — 직업 항목 캡션

- 소형. 항목 라벨 자막 옆에 배치
- `disclaimer`와 병존
- 섹션 3-d, 4-d 구간 고정

### addiction — 중독 소재 전용 캡션

- `career`보다 한 단계 높은 시인성
- **`career`와 같은 자리에 교체 방식으로 노출.** 동시에 뜨지 않음
- 해당 문단 구간에만

**교체 처리 주의**: 섹션 4에서 `career` → `addiction` → `career` 순으로 두 번 전환됩니다. 전환 시 깜빡임이 생기지 않도록 크로스페이드를 쓰거나, 앞 캡션의 페이드아웃과 뒤 캡션의 페이드인을 겹치십시오.

---

## 4. 반드시 지켜야 할 규칙

- **문구를 컴포넌트에 하드코딩하지 마십시오.** 편별로 달라집니다. props로 받습니다
- **타임코드를 컴포넌트에 넣지 마십시오.** 상위 Sequence가 제어합니다
- **시인성 순서를 바꾸지 마십시오.** `medical`이 가장 눈에 띄어야 합니다
- **`medical`은 어떤 경우에도 가려지지 않아야 합니다.** 다른 요소와 z-index가 충돌하면 `medical`이 위입니다
- **`career`와 `addiction`을 동시에 띄우지 마십시오.** 교체 관계입니다
- **`disclaimer`는 다른 자막이 떠도 유지됩니다.** 배치가 겹치지 않게 설계하십시오
- 색상·폰트는 **시리즈 공통 스타일을 재사용**하고, 이 컴포넌트에서 새로 정의하지 마십시오. 단 `medical`의 붉은 계열은 경고 전용 색으로 공통 스타일에 추가하는 것이 맞습니다

## 5. 배치

```
┌─────────────────────────────────────┐
│                                     │
│           (본문 영역)                │
│                                     │
│  [career / addiction]  ← 항목 라벨 옆 │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  [medical]  구간 노출 시        │  │
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │  [disclaimer]  상시            │  │
│  └───────────────────────────────┘  │
│  ─── 자막 안전 영역 160px ───        │
│           (내레이션 자막)            │
└─────────────────────────────────────┘
```

`medical`이 뜨는 동안 `disclaimer`가 아래로 밀리는 방식도 가능합니다. 다만 위치 이동이 시선을 끌면 오히려 산만해지므로, **처음부터 두 자리를 비워두는 방식**을 권합니다.

## 6. 검수 항목

- [ ] 네 종류의 시인성이 확실히 구분되는가
- [ ] `medical`이 가장 눈에 띄는가 — **다른 자막과 비슷해 보이면 실패**
- [ ] `disclaimer`가 섹션 3~4 내내 유지되는가
- [ ] `medical` 노출 시 `disclaimer`와 겹치지 않는가
- [ ] `career`와 `addiction`이 동시에 뜨지 않는가
- [ ] 교체 시 깜빡임이 없는가
- [ ] 자막 안전 영역(하단 160px)을 침범하지 않는가
- [ ] 문구가 props로 주입되는가 (하드코딩 없음)
- [ ] 타임코드가 컴포넌트 밖에서 제어되는가
- [ ] 1080p에서 문구가 한 줄에 들어가는가 — 넘치면 줄바꿈 처리 확인

## 7. 편별 문구 목록 (목양·목음편)

| 종류 | 문구 | 노출 구간 |
|---|---|---|
| disclaimer | 일반적인 체질별 경향을 설명한 것으로, 절대적인 특성이 아닙니다. | 섹션 3 시작 ~ 섹션 4 끝 |
| medical | 복용 중인 혈압약을 임의로 중단하지 마시고 반드시 담당 의사와 상의하십시오. | 섹션 3 혈압 문단 |
| career | 직업 적성은 경향이며, 진로 판단의 근거가 아닙니다. | 섹션 3 직업 구간 / 섹션 4 직업 구간(알코올 문단 제외) |
| addiction | 알코올 의존은 전문적인 치료가 필요한 문제입니다. | 섹션 4 알코올 문단 |

**정확한 프레임 구간은 TTS 실측 후 확정합니다.** 지금은 컴포넌트만 만들고, Sequence 값은 임시로 두십시오.

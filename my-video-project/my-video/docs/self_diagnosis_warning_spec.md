# SelfDiagnosisWarning — 자가진단 경계 화면 사양서

**용도**: 섹션 5 자가진단 경계
**첫 적용**: 기본 시리즈 ① 목양·목음편
**재사용**: **전 편 필수 구간.** 제작표준 6-1이 모든 심화편에 자가진단 경계 배치를 요구합니다. 문안만 편별로 조정하고 구조는 그대로 씁니다

---

## 1. 이 구간의 딜레마

이 영상은 9항목에 걸쳐 체질 특징을 상세히 설명했습니다. **그만큼 시청자가 스스로 판단하려는 충동이 큽니다.** 이 구간은 그것을 막는 자리입니다.

그런데 두 방향으로 실패할 수 있습니다.

| 실패 | 증상 |
|---|---|
| **너무 강하면** | 겁을 주게 되고, 앞의 9항목이 무의미해 보임. "그럼 왜 봤나" |
| **너무 약하면** | 흘려듣고 자가진단을 함. 안전장치가 작동하지 않음 |

**균형점은 이렇습니다.** 앞 내용을 부정하지 않으면서, 그것만으로는 부족하다는 것을 분명히 하는 것. 앞서 2-b 도식에서 "부정이 아니라 확장"으로 처리한 것과 같은 원리입니다. 여기서도 **"9항목은 틀렸다"가 아니라 "9항목으로는 확정할 수 없다"**입니다.

그리고 **막기만 하고 끝내지 않습니다.** 시청자가 아무것도 못 하는 상태로 남으면 오히려 무시하게 됩니다. 마지막에 "그렇다면 무엇을 하면 되는가"를 줍니다.

## 2. 인터페이스

```ts
type Props = {
  lead: string;          // '이 영상만 보고 스스로 체질을 판단하지 마십시오'
  variables: string[];   // ['성격', '체형', '직업 적성', '음식 기호']
  keyLine: string;       // '이것들을 다 모아도 체질을 확정할 수는 없습니다'
  onlyWay: string;       // 맥진 문안
  fallback: string;      // '차라리 골고루 드시는 편이 낫습니다'
  stageStartsSec?: number[];
};
```

## 3. 연출 구성

| 단계 | 화면 | 대응 내레이션 |
|---|---|---|
| 1 | 경고 리드 — 이 구간에서 가장 큰 텍스트 | 이 영상만 보고… 판단하지 마십시오 |
| 2 | 가변 요소 4개 제시 — 성격 · 체형 · 직업 적성 · 음식 기호 | 성격도, 체형도, 직업 적성도… |
| 3 | **강조 자막** — "이것들을 다 모아도 체질을 확정할 수는 없습니다" | 오늘 여러 가지 항목을… |
| 4 | 맥진 — 유일한 방법 | 양쪽 손목의 요골동맥을 짚는… |
| 5 | 대안 — 모르면 골고루 | 차라리 골고루 드시는 편이… |

### 각 단계의 요령

**2단계 — 앞에서 다룬 항목을 회수합니다.** 성격·체형·직업 적성·음식 기호는 모두 이 영상에서 설명한 것들입니다. 시청자가 "방금 본 것들"로 알아보게 하십시오. 항목 라벨(`ItemLabel`)과 같은 명칭·형식을 쓰면 연결이 즉시 성립합니다.

**3단계가 이 구간의 정점입니다.** 강조 자막으로 지정되어 있습니다. 2단계에서 모인 요소들이 이 문장 앞에서 무력해지는 구도가 이상적입니다 — 다만 요소들에 X를 치거나 사라지게 하지 마십시오. 앞 내용의 부정이 됩니다.

**4단계는 대안 제시입니다.** 경고 톤에서 정보 톤으로 전환됩니다. 맥진 이미지(`8체질_맥진법_1.jpg` / `_2.jpg`)를 쓸 수 있습니다 — **이 시리즈에서 실사 이미지를 쓰는 몇 안 되는 자리**입니다. 인물 얼굴이 나오지 않는 컷을 고르십시오.

**5단계는 톤을 낮춥니다.** 경고가 아니라 조언입니다. 시청자가 지금 당장 할 수 있는 일을 주는 자리이므로 부드럽게.

## 4. 반드시 지켜야 할 규칙

### 톤

- **공포를 유발하지 마십시오.** 붉은 경고색, 위험 아이콘, 큰 느낌표 금지. 이 구간은 `SafetyCaption medical`과 성격이 다릅니다 — 저쪽은 복약 중단이라는 즉각적 위해를 막는 것이고, 이쪽은 판단 유보를 요청하는 것입니다
- **앞 내용을 부정하지 마십시오.** 9항목에 X를 치거나 지우거나 회색으로 죽이지 마십시오. "틀렸다"가 아니라 "이것만으로는 부족하다"입니다
- **시청자를 나무라는 인상을 주지 마십시오.** "~하지 마십시오"가 반복되면 훈계로 들립니다. 화면에서는 금지보다 **사실 제시**로 처리하십시오
- 5단계는 반드시 **부드럽게** 끝납니다. 이 구간이 강한 톤으로 끝나면 시청자가 불쾌감을 안고 클로징으로 갑니다

### 표현

- **맥진을 "간단한 방법"으로 그리지 마십시오.** 훈련이 필요한 진단법이고, 쉬워 보이면 따라 하려 합니다
- **맥진 방법을 설명하지 마십시오.** 요골동맥이라는 위치까지가 한계입니다. 짚는 법·판별법을 화면에 넣으면 자가 시도를 유발합니다
- **특정 의료기관·시술을 유도하지 마십시오.** 의료광고 규정에 걸립니다
- "치료" "완치" 등 효과 단정 표현 금지

### 배치

- 본문 발자국 **y < 686**
- disclaimer 자막은 섹션 3~4 구간이므로 이 섹션에는 뜨지 않습니다. 하단이 비교적 자유롭습니다
- 화면 유지 시간을 충분히 확보하십시오. 읽을 시간이 필요한 구간입니다

**화면 출처**: `출처: 권도원, 「중환자와 채식」, 빛과소금 1994년 5월호 / 「체질은 왜 여덟인가」, 1995년 5월호 / 월간조선 2011년 5월호`

## 5. 문안

```ts
lead: '이 영상만 보고\n스스로 체질을 판단하지 마십시오'
variables: ['성격', '체형', '직업 적성', '음식 기호']
keyLine: '이것들을 다 모아도\n체질을 확정할 수는 없습니다'
onlyWay: '체질을 아는 방법은\n양쪽 손목의 요골동맥을 짚는 팔체질 맥진뿐입니다'
fallback: '체질을 모르는 상태에서 섣불리 체질식을 하면\n오히려 건강을 해칠 수 있습니다\n\n권도원 박사님은 그런 경우라면\n차라리 골고루 드시는 편이 낫다고 하셨습니다'
```

`variables`에 "모두 가변적입니다"라는 성격을 함께 표시하십시오. 네 항목이 나열만 되면 왜 부족한지가 전달되지 않습니다.

## 6. 검수 항목

- [ ] 공포·위협 인상이 없는가 — 붉은 경고색, 위험 아이콘, 느낌표 없음
- [ ] 앞의 9항목을 부정하지 않는가 — X·지우기·회색 처리 없음
- [ ] 훈계조로 읽히지 않는가
- [ ] 3단계 강조 문장이 이 구간의 정점으로 읽히는가
- [ ] 가변 요소 4개가 "방금 본 것"으로 인식되는가 — 항목 라벨과 명칭·형식 일치
- [ ] 맥진이 간단해 보이지 않는가
- [ ] 맥진 방법을 설명하지 않는가
- [ ] 실사 이미지 사용 시 인물 얼굴이 없는가
- [ ] 특정 의료기관·시술 유도가 없는가
- [ ] 5단계가 부드럽게 끝나는가
- [ ] 화면 유지 시간이 충분한가
- [ ] y < 686
- [ ] **시청자가 "그럼 어떻게 하라는 거지"로 끝나지 않는가** — 최종 판단 기준

## 7. 이 구간의 위치

앞 구간(4-i)이 **"다음 편에서 다루겠다"는 예고로 끝납니다.** 여기 첫 문장의 "그런데"가 그 전환을 받아야 합니다.

뒤에는 클로징(섹션 6)이 이어집니다. 이 구간이 무겁게 끝나면 클로징의 다음 편 예고가 겉돕니다. **5단계에서 톤을 충분히 낮춰 두십시오.**

체형 반례 문장(섹션 3의 "육영수 여사처럼 그렇지 않은 경우도 있습니다")과 **수미상관**입니다. 시각적으로 연결할 수 있으면 좋으나 필수는 아닙니다.
